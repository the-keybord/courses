# Robot Factory Creation - Course Agent Rules

This file complements the global repository [`AGENTS.md`](../AGENTS.md) with rules specific to the **Robot Factory: Creation** (Level 1) course.

## Course Context & Architecture
- **Course Name**: Robot Factory: Creation (Level 1)
- **Course Code**: RBF1
- **Target Age Group**: **11–14 years old** (beginners with no prior robotics, electronics, or programming experience).
- **Core Pillars**:
  1. **3D Modeling in Fusion 360**: Parametric design of robot chassis and functional parts, 3D printing on Bambu Lab printers.
  2. **BBC Micro:Bit Platform**: Block-based programming in Microsoft MakeCode, transitioning to MicroPython, leveraging built-in sensors (accelerometer, compass, LEDs, buttons, microphone, speaker).
  3. **robot:bit Expansion Board**: Motor driver integration, servo control, sensor connectivity, power management for a mobile robot.
  4. **Competition**: End-of-course robotics challenge with autonomous and teleoperated tasks.
- **Lesson Structure**: Guided hands-on format with theory presentations, step-by-step teacher demonstrations, and practical exercises.
- **Lesson Duration**: Standard **120 minutes** (2 hours) per lesson.

## Language Rules
- **Course Content**: All lesson plans, student guides, teacher instructions, quizzes, and worksheets must be created in **Romanian**.
- **Agent Meta & Communication**: Agent guidelines, commit messages, and conversations with the repository maintainer are in **English**.

## Lesson Content & Writing Style
- **Clear & Engaging Technical Tone**: Write in a direct, technically accurate style that is warm and accessible for kids aged 11–14 encountering microcontrollers and programming for the first time.
- **Step-by-Step Clarity**: Every practical exercise must include explicit step-by-step instructions that a first-time programmer can follow without prior experience.
- **MakeCode Block Descriptions**: When describing MakeCode exercises, specify the exact block names, the category they belong to (Basic, Input, Logic, Loops, Variables, LED, Music, Radio), and the expected behavior in the simulator.

## Formatting Policy: No ASCII Art Diagrams or ASCII Pseudo-Tables
- **Strict Prohibition**: Absolutely NO ASCII art diagrams, ASCII circuit drawings, ASCII layout maps, or ASCII box pseudo-tables in lesson README files.
- **Literal Prose & Essay Explanations**: Explain connections, workflows, and structures in comprehensive literal text and narrative essay form.
